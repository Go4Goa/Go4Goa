## Stack
Delegated by the user on 29 October 2026: React, TypeScript, Vite, Node API, PostgreSQL/PostGIS and S3-compatible object storage. Local-first implementation in `/Users/zakkrevitt/code/GO-GOA`. The user will coordinate deployment separately through the orchestrator.

## Users
Goa residents reporting civic problems and joining local action, community meetup organizers, and moderators. Mobile use outdoors and on weaker networks is the primary setting.

## Product Purpose
Make photo-based trash and infrastructure reports visible safely, connect them to practical source-backed resources, and organize public civic events.

## Operating Context
A map is the operational center, with an accessible list. Reports move through moderation before publication. Meetups publish immediately for signed-in creators, with a dedicated page and share link; organizer approval is not required. Phone verification establishes a private account; public identity is a unique pseudonymous username. All event dates display in Asia/Kolkata.

## Capabilities and Constraints
The supplied brief governs reporting, exact/blurred location, moderation, events, capacity, calendar export, attendance, consent-based notifications, immutable points, resources, offline states and account controls. Never claim an upload succeeded before server acceptance. Separate private and public data. Never modify the reference repositories. Never use Device Hub without explicit approval for that occasion.

Resources and Directory cover trash and infrastructure only. A Directory button in Resources opens the authorized ActForGoa community search and CRM port, with source evidence and browser-local notes; Directory routes keep Resources active in the five-tab navigation. Directory rows prioritize a name, short description and useful location. Both surfaces link header attribution to ActForGoa and place “Need more resources? Visit ActForGoa” below the content. The Resources footer contains only that bold onward link. Wider environmental or civic subject matter alone does not qualify a listing for these surfaces.

## Brand Commitments

No eyebrow text, em dashes, sideflag containers, fabricated impact metrics or gamified rankings. User requested liquid-glass bottom navigation between reporting, events, map and profile. ## Product Principles
Privacy is enforced by server projections. A report leads to useful next actions. Moderation decisions remain auditable. Notifications require verified channels and explicit consent. Failures remain visible and recoverable.
